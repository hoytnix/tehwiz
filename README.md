## ⚡ The Philosophy

> *"How do Mario's Goombas know where to walk?"*  
> When asked at age five in front of a CRT television, the answer wasn't a corporate API pitch—it was magic.

The modern web spent the last two years falling over itself to rent 400-billion-parameter cloud APIs: funneling user keystrokes, webcam feeds, and private reasoning through remote data centers, bound by the speed of light to Northern Virginia and billed by the token.

**TehWiz rejects the cloud toll booth.**

We build sovereign, on-device intelligence. If a model cannot execute on the silicon already sitting in your pocket—offline on an iPhone SE or an everyday laptop at 70–110 tokens per second with zero telemetry leaving the device—it does not inhabit its world. It is just an expensive puppet.

## 🏗️ Architecture: Static By Design

```
                     ┌────────────────────────────────────────┐
                     │         TehWiz Development Host        │
                     │  pnpm dev (process.env.NODE_ENV=dev)   │
                     └───────────────────┬────────────────────┘
                                         │
                   ┌─────────────────────┴─────────────────────┐
                   │                                           │
                   ▼                                           ▼
      ┌─────────────────────────┐                 ┌─────────────────────────┐
      │   Local Content Studio  │                 │    Hot Module Reload    │
      │   GET/POST/PUT/DELETE   │                 │    Real-Time Reader     │
      │    localhost:3000/editor│                 │   src/modules/*/data/   │
      └────────────┬────────────┘                 └────────────┬────────────┘
                   │ Writes JSON directly to disk              │
                   ▼                                           ▼
      ┌─────────────────────────────────────────────────────────────────────┐
      │  Persistent Source of Truth (*.json)                                │
      │  blogData.json • portfolioData.json • vlogData.json • promptsData.json │
      └──────────────────────────────────┬──────────────────────────────────┘
                                         │
                                         ▼ pnpm build (Next.js output: 'export')
      ┌─────────────────────────────────────────────────────────────────────┐
      │  Static HTML Export Directory (/out)                                │
      │  - 40 Fully Prerendered Static Pages (HTML/CSS/JS)                  │
      │  - Zero Node.js runtime required                                    │
      │  - .nojekyll (protects _next/ bundles)                              │
      │  - CNAME (tehwiz.com)                                               │
      │  - Dev routes (/editor, /api/admin) scrubbed automatically          │
      └──────────────────────────────────┬──────────────────────────────────┘
                                         │
                                         ▼ Push to main (GitHub Actions)
                     ┌────────────────────────────────────────┐
                     │          GitHub Pages Edge CDN         │
                     │          $0/mo Hosting Forever         │
                     └────────────────────────────────────────┘
```

* **100% Static HTML Export**: Prerendered via Next.js 15 SSG (`output: 'export'`) with unoptimized image pipelines compatible with raw static file hosts.
* **Zero-Leak Localhost Studio**:
  * Local CRUD Editor at `/editor` powered by [`/api/admin`](file:///home/oloty/Dev/TehWiz/src/app/api/admin/route.ts).
  * Enforces loopback host protection (`localhost`, `127.0.0.1`, `::1`) and returns 404 in production.
  * Post-build scrubber ([`scripts/clean-export.js`](file:///home/oloty/Dev/TehWiz/scripts/clean-export.js)) guarantees no editor code or API stubs enter the production bundle.
* **Quiet Dark Editorial System**: Hand-tuned aesthetic in `globals.css` using ink `#0A0B10`, card `#12141C`, violet `#8B7CFF`, and typography set in Fraunces & JetBrains Mono. Zero neon gamer glow; pure editorial discipline.
* **Full Syndication**: Dynamic RSS (`/rss.xml`), Atom (`/feed.xml`), Google Sitemap (`/sitemap.xml`), and rich `schema.org` JSON-LD graphs rendered statically at build time.

## 🚀 Quickstart & Local Development

### Prerequisites
* **Node.js** (v20+ recommended)
* **pnpm** (`corepack enable && pnpm install`)

### 1. Clone & Install
```bash
git clone https://github.com/hoytnix/TehWiz.git
cd TehWiz
pnpm install
```

### 2. Launch Local Environment with Studio
```bash
pnpm dev
```
* **Public Site Preview**: [http://localhost:3000](http://localhost:3000)
* **Localhost Content Studio**: [http://localhost:3000/editor](http://localhost:3000/editor)  
  *(A discrete `[Editor]` badge automatically appears in the navigation bar while in dev mode)*

### 3. Compile Static Export
```bash
pnpm build
```
This builds all 40 static pages, generates the XML feeds, and outputs a sanitized [`out/`](file:///home/oloty/Dev/TehWiz/out) directory ready for GitHub Pages or Cloudflare Pages.

### 4. Deploying to GitHub Pages
Deployment is handled automatically on every push to `main` via the included workflow [`.github/workflows/deploy.yml`](file:///home/oloty/Dev/TehWiz/.github/workflows/deploy.yml).

To enable GitHub Pages in your fork or repository:
1. Go to **Settings** → **Pages**.
2. Under **Build and deployment** → **Source**, select **GitHub Actions**.
3. Push to `main` and your static site will be live on edge servers worldwide.
