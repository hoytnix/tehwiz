# System Patterns — TehWiz

- Shell: flat page, header hairline, content max-w-6xl, footer hairline. No orbs, no grids, no nested app-box.
- Cards: flat surface #141518, 1px hairline, radius 14px, no glow, no lift, no scale.
- Buttons: primary = bone solid + black text; secondary/outline = hairline; no gradients.
- Type: Jakarta semibold headlines; JetBrains Mono ONLY for kickers/labels/data.
- Accent amber #F5B83D: live status, key figures, focus rings. Nothing else glows.
- Motion: color/border fades only, honor prefers-reduced-motion.
